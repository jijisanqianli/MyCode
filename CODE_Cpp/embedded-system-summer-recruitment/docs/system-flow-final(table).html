二、数据包流向（传感器数据上行 + 历史）

DATA FLOW · UPSTREAM
采集 DHT22+HW-390 → Env/SoilDriver→ SensorService (updateAndGet: 短临界区打包 + 写 HistoryService) → sensorTask (每 2s)
→ OLED oledQueue→ oledTask→OledDisplayDriver →OLED 屏
→ MQTT latestDataQueue→ mqttTask→MqttService →MqttDriver →EMQX Broker →MQTTX/网页 (JSON 含 mode + channels 状态)
→ 历史 HistoryService →WebServerController →网页 Chart.js 曲线 (GET /api/history, 2s 采样, 2000 条)
→ 自动灌溉 autoIrrQueue→ controlTask (AUTO 模式 + 阈值判断在 sensorTask, 状态变化才发)

三、指令流向（控制下行 + 模式状态机）

COMMAND FLOW · DOWNSTREAM
MQTT 指令 MQTTX/网页→ EMQX Broker→ MqttDriver→ MqttService (解析 pump/mode; 连接后清除 retain 防重放)
HTTP 指令 网页按钮→ WebServerController (on/off/mode 均发 manualIrrQueue, 控制收敛)
汇聚 manualIrrQueue → controlTask (唯一执行者; pump 指令自动切 MANUAL)
执行 IrrigationService→ IrrigationDriver →LED / 水泵
状态回传 MqttService→ channels 字段 →页面状态实时刷新 (HTTP 2s 轮询 + MQTT 推送)
