分层架构 (Layering)

严格遵从单向依赖原则 $\mathcal{L}_{\text{Ctrl}} \to \mathcal{L}_{\text{Svc}} \to \mathcal{L}_{\text{Drv}}$。Controller 处理外部协议，Service 完成业务逻辑，Driver 隔离底层硬件 GPIO/I2C 寄存器。

$\text{Dependency: } \text{Upper} \Downarrow \text{Lower}$

任务模型 (Task Model)

每个任务定义为三元组 $\tau_i = (P_i, C_i, T_i)$，其中 $P_i$ 为优先级，$C_i$ 为 Worst-Case 运行时间，$T_i$ 为调度周期。调度器采用 Fixed-Priority Preemptive (固定优先级抢占)。

$U = \sum_{i=1}^{N} \frac{C_i}{T_i} \le N(2^{1/N} - 1)$

跨核 IPC 通信 (Queues)

通过 FreeRTOS Queue 传递深拷贝结构体（Value Passing），实现 Core 0 与 Core 1 间无锁安全解耦，时延模型满足 $\tau_{\text{IPC}} = \tau_{\text{wait}} + \tau_{\text{copy}}$。

$\text{Queue}_{\text{capacity}} = k \cdot \text{sizeof}(\mathbf{Struct})$
