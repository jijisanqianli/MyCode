三层解耦架构

严格遵循 Controller $\to$ Service $\to$ Driver 单向依赖规范。Controller 抽象网络路由，Service 封包核心灌溉算法，Driver 隔离 GPIO/I2C/SPI 底层细节。

FreeRTOS 队列通信

利用 xQueueSend 与 xQueueReceive 消除多任务临界区竞态。传感器采样与云端通信、硬件控制完全异步化。

双向数据链路

包含 **数据包上行流**（DHT22/Soil $\to$ OLED / MQTT Telemetry）与 **控制指令下行流**（HTTP / MQTT $\to$ Relay Actuator），具备抢占式仲裁。
